# KPL GAME UI 规范 v1

基线来自现有 `kpl2k/portal/styles.css`；规范是新游戏与后续改版验收标准，不代表所有旧游戏已完全合规。

浅色电竞产品风格：白/淡灰蓝底、深蓝正文、红蓝环境渐变、大留白、细边框、克制动效。各游戏可自选 accent；不要求玩法布局相同。禁止满屏霓虹、粒子、HUD、重玻璃、循环发光和低可读性字体。

| 项目 | 约定 |
| --- | --- |
| 背景 / 正文 / 辅助 | #f3f6fc / #172844 / #52647f |
| 边框 | rgb(49 78 125 / 18%) |
| 字体 | system-ui、Segoe UI、PingFang SC、Microsoft YaHei、sans-serif；字体本地提供，不请求 Google Fonts |
| 内容宽度 | 1120–1200px，窄屏保留 12–16px 内边距 |
| spacing | 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64px |
| radius | 控件 10–12px；卡片 14–18px；主卡 18–20px |
| 字号 | Hero 38–64px；页面标题 28–36；卡片标题 18–24；正文 14–16；辅助 12–14 |
| 触摸区域 | 主要操作至少约 44×44px |
| 动效 | 150–220ms，hover/press/selection/状态反馈；reduced-motion 关闭非必要动画 |

导航用真实链接，操作用 button，input 有 label，focus-visible 清晰。搜索下拉支持方向键、Enter、Escape；Modal 有名称、焦点约束与关闭后焦点恢复；适当 aria-live；正确/错误同时提供文字或符号，装饰 aria-hidden。正文对比度目标 4.5:1。

每个游戏提供“← 游戏中心”回到 `/`；独立本地开发允许回到正式 Hub，集成站统一根路径。禁止游戏间硬编码跳转。

逐个实测 320 / 390 / 768 / 1024 / 1366px：320 无横向溢出；390 可完整游玩；长姓名/队名换行或省略且保留可获取全称；搜索不出屏；Modal 可滚动；表格采用独立横向滚动区或移动卡片。重要信息不使用 10/11px。

Portal 只加载自身静态资源，不预取游戏数据。图片合理尺寸、优先 WebP/AVIF，非首屏 lazy；未来 Timeline 按需分片。核心 HTML/CSS/JS/JSON/font/icon 同源。外链资料不等于运行依赖，统计失败不得阻断游戏。
